# Shizuku-Web

整活仓库：把安卓玩机神器 [Shizuku](https://shizuku.rikka.app/) 的界面 **1:1 复刻**成一个网页。

所有按钮都能点、都有反馈（配对动画、启动转圈、开关、抽屉、对话框一应俱全），**但什么实际作用都没有**——既不会真的启动 Shizuku，也不会真的给你授权。

## 功能（假的）

- 完整复刻主页：未运行/正在运行状态卡片、API 版本、uid、应用列表
- 三个启动分区：root 启动 / 无线调试启动（含配对码对话框）/ ADB 命令启动
- 侧边抽屉：Shizuku / 使用 Shizuku / 关于
- 溢出菜单：开发者选项（假开关）、通知、帮助、关于
- 可展开步骤、代码块、Material 3 浅色主题

## 本地预览

直接用浏览器打开 `index.html` 即可。

## GitHub Pages

仓库 Settings → Pages → Deploy from a branch → `main` / `root`，稍等即可访问。
